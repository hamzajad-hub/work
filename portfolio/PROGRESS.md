- [x] **Two honest limits of that, worth knowing before you rely on it.** First, **the message is not sent until the visitor presses send inside WhatsApp.** The site can write the message for them and open the chat; no website is allowed to send a message on someone else's behalf. Second, the number is **not** a running count like `REQ-001`. A plain site with no server has nowhere to keep a count, so the number is built from the date plus four letters picked at random from an alphabet with no O/0 or I/1 to mistype — unique in practice, but not sequential, and it is minted in the visitor's browser rather than by you. Their own browser keeps a short list of the numbers it has made (only the number, the day and what it was for — never their name and never their text, capped at the last 20) so they can find theirs again
